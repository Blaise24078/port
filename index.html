Temper, a project to make coding arduinos more accessable to people that don't know how to code. It implements code blocks to be capable of basic arduino programs on multiple boards. It's free to use with no telemetry, like all of my work. It was designed for MacOS but windows support might come in the future.



This is rift, a custom coding language made for efficiency and speed. It utilizes multicore distribution and simple syntax to make it more practical to use. It uses .rf files, and can do most stuff that Python can do, with some upsides such as making multicore work much simpler. It was also built around the idea of making ML easier to do. It includes access to utilize the GPU without any installs, only if you want to in case you don't ahve one.
